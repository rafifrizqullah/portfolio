# Portfolio

Personal portfolio website for Muhammad Rafif Rizqullah, showcasing projects, resume, skills, and contact information.

## Overview

A responsive static portfolio website built with HTML, CSS, and Bootstrap. The site includes a hero section, about section, project highlights, and contact navigation.

## Features

- Responsive layout using Bootstrap 5
- Navigation menu with scrollspy sections
- Downloadable resume link
- Personal introduction and profile imagery
- Static deployment-ready structure

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## File Structure

- `index.html` — main website markup
- `style.css` — custom styles for the portfolio
- `assets/` — images, favicon, and resume files

## Usage

1. Open `index.html` in a browser.
2. Optionally deploy to any static web host such as GitHub Pages, Netlify, or Vercel.
